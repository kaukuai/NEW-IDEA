# PROJECT MASTER PROMPT
# 打造零 AI 成本、低維護、可長期商業化的多人分帳平台

## 一、專案核心目標

你是一支由產品經理、市場研究員、UI/UX 設計師、全端工程師、演算法工程師、資安工程師與商業策略顧問組成的自主開發團隊。

你的任務是研究現有市場的分帳產品，並從零開始設計、開發、測試與交付一款真正可以商業化的多人分帳工具。

本專案有三個最高優先級原則：

**1. 產品不依賴任何生成式 AI**

**2. 產品完成後，應盡可能不需要持續維護**

**3. 產品應在沒有付費 API、後端伺服器及持續訂閱成本的情況下正常使用**

我希望這是一款像計算機一樣可靠的工具：一旦開發完成，只要使用者的裝置與執行環境相容，就能長期運作，而不需要每天監控、更新模型、支付 Token 費用或維護大量後端基礎設施。

注意：這是最小化維護與長期依賴的設計目標，不得宣稱任何網站、瀏覽器或第三方服務能保證永久零維護。

最終成果必須是可以實際執行、部署、測試、擴充與商業化的完整產品，而非展示用 Demo。

## 二、嚴格禁止的功能與技術

### 2.1 禁止任何需要生成式 AI 的產品功能

正式產品不得包含：

- OpenAI API
- Gemini API
- Claude API
- 其他大型語言模型 API
- AI Agent
- AI 聊天客服
- AI 生成文字
- AI 分帳建議
- AI 收據辨識
- AI 語音辨識
- AI 自動生成財務報告
- 需要模型推論服務的任何功能
- 依賴模型訂閱或 Token 計費的功能

**Codex 可以在開發過程中使用 AI 協助寫程式，但最終產品的執行不可以依賴 AI。**

使用者所有分帳操作、財務計算、最佳化、資料整理與報表，都必須使用確定性演算法及一般程式邏輯完成。

### 2.2 盡量避免持續付費的基礎設施

優先避免：

- 付費後端主機
- 需要管理的伺服器
- 持續運作的資料庫主機
- 付費第三方 API
- 定期執行的雲端工作
- 需要人工操作的部署流程
- 複雜的微服務架構
- 依賴頻繁更新的套件
- 不必要的即時通知系統
- 需要持續支付授權費的第三方 SDK

如果某項技術會帶來持續成本或維護義務，必須先研究是否能用簡單的前端技術替代。

不得為了功能完整而犧牲整個產品的長期可維護性。

### 2.3 不允許虛假的零維護承諾

請區分：

- 完全在使用者裝置上運算的功能
- 需要靜態網站託管的功能
- 需要外部平台協作的功能
- 需要後端及持續營運的功能

只有第一類可以真正做到幾乎沒有日常營運負擔。

其他功能必須如實列出風險與依賴。

## 七、第五階段：核心數學與最佳化演算法

此專案的核心競爭力是準確、可靠且高效率的分帳演算法。

絕對不使用 AI 計算。

### 7.1 基本計算

每位成員：

淨餘額 = 已墊款金額 − 應分攤金額 + 已轉出金額 − 已收到金額

正數為應收，負數為應付。

必須確保：

- 全員淨額合計為零。
- 不產生額外金額。
- 不會重複計算轉帳。
- 所有計算以整數最小貨幣單位處理。
- 每筆結算可追溯。
- 修改費用後可正確重新結算。

### 7.2 真正的最少轉帳次數

不能只使用一般貪婪演算法，然後宣稱結果是最佳解。

請研究與實作：

- Backtracking
- Dynamic Programming
- Zero-Sum Subset Partition
- Branch and Bound
- 其他確定性最佳化方法

針對適合的群組規模，提供可以證明全域最優的演算法。

對於大群組，可以採用高效率近似解，但必須清楚標示。

建立兩種主要模式：

**模式 A：最少轉帳次數**

優先減少總交易筆數。

**模式 B：最簡單操作**

優先減少每個人需要接觸的收付款對象。

在不同偏好互相衝突時，必須明確告知使用者取捨。

### 7.3 真實測試案例

總共 11 人。

已付款：

旅伴一：
- 聚餐一 1000
- 聚餐二 2000
- 晚餐 6070

旅伴二：
- 採買 7205

旅伴三：
- 午餐 3370
- 民宿 23200

旅伴四：
- 雜支 534

旅伴五：
- 雜支 434

另有六位完全沒有付款：

A、B、C、D、E、F。

預期：

總花費：43,813 元

每人：3,983 元

淨餘額：

旅伴一：+5,087

旅伴二：+3,222

旅伴三：+22,587

旅伴四：-3,449

旅伴五：-3,549

A～F：每人 -3,983

以下是一個已知可行的 10 筆轉帳解：

旅伴四 → 旅伴三：3,449
旅伴五 → 旅伴三：3,549
A → 旅伴三：3,983
B → 旅伴三：3,983
C → 旅伴三：3,983
D → 旅伴三：3,640
D → 旅伴一：343
E → 旅伴一：3,983
F → 旅伴一：761
F → 旅伴二：3,222

請確認總額正確，並透過精確求解器驗證是否存在更少筆數的解。

不能事先認定 10 筆就是最優解。

### 7.4 自動化測試
