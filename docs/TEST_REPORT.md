## 人工檢視與自動化界線

已實際檢視桌面費用頁、首頁、375px結算與深色設定截圖；文字、結算箭頭／金額、主要操作沒有被裁切。最初輔助文顏色對比不足已修正。掃描仍有若干`color-contrast` incomplete（SVG／圖形／短標籤等），沒有把incomplete計為passed checks或刪除規則；需要進一步人工對比與真實輔助技術檢查。

深色模式掃描原先在150ms主題顏色過場中取樣，修正測試等待過場結束後再掃；產品對比標準沒有降低。注入axe使用DevTools執行，沒有將產品CSP改成unsafe-inline。清空／匯入測試等待前一筆交易與dialog完成，不以腳本在模態視窗未關閉時操作底層檔案欄。

鍵盤、屏幕閱讀器、色覺情境、真機觸控與OS分享仍不能由自動0違規推導為全數通過。
