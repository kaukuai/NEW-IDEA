This repository is now Fold / 合帳, an offline-first expense splitter. Read PROJECT_STATE.md and PROGRESS.md before continuing. The current user brief is docs/PROJECT_BRIEF.md. Previous Relay and Offcut experiments are abandoned and recoverable through Git history; do not resume them.

Correctness > stability > low maintenance > UX > feature count. No generative AI, remote calculation, paid APIs, cloud database, account dependency or tracking in the product. Use integer minor units and deterministic algorithms. Never label a heuristic globally optimal.

Keep money/domain, persistence and UI separate. Validate backups before atomic replacement. Maintain schema migration and user-owned exports. Run type checking, domain/property tests, build and relevant browser tests after changes. Document actual results and unverified limits.

Routine local research, code and tests are authorized. Public deployment, spending, real-user private data, external communications and irreversible external operations need explicit authorization. Do not request permission for routine development. Do not promise background work after the turn ends.

All publishable examples, tests and brief documents use aliases. The original user-provided identities remain only in private local development history/backups. Never publish the local work branch, all branches, or backup bundles without reviewing that private history. GitHub updates use main. Preserve private local history without merging it into public main.
